# Brand assets — yousiffarra.com

Production brand kit. Referenced from Site Settings (Settings → Identity, Brand Colors) and the navbar/layout.

## Files

| File | Use |
|---|---|
| `logo.svg` | Primary wordmark — for light backgrounds (dark text + coral accent) |
| `logo-dark.svg` | Wordmark variant for dark backgrounds (white text + coral accent) |
| `favicon.svg` | Modern SVG favicon — used by the layout |
| `favicon-source.svg` | The `<YF/>` developer signature — for brand applications |

## Palette

| Role | Hex |
|---|---|
| Primary (indigo) | `#4F46E5` |
| Accent (coral) | `#F97316` |
| Text dark | `#0F172A` |
| Surface light | `#FAF9F6` |

These are also seeded into the `settings` table on a fresh install.
